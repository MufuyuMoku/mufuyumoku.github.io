# mufuyumoku.github.io

Akar situs GitHub Pages milik MufuyuMoku. Isinya sengaja minimal:

- `.well-known/assetlinks.json`: Digital Asset Links untuk aplikasi Android Saku Pajak
  (`io.github.mufuyumoku.sakupajak`), supaya aplikasinya tampil tanpa bilah alamat.
- `index.html`: halaman kosong yang menunjuk ke `/tax/`.
- `.nojekyll`: supaya folder `.well-known` ikut terbit.

Situs proyek lain (misalnya `/tax/` dan `/portofolio/`) tetap dilayani dari repositorinya masing-masing.
